# ryujinx-xbox

Experimental port of [Ryubing](https://git.ryujinx.app/ryubing/ryujinx) (the community continuation of Ryujinx) to Xbox Series X|S in Developer Mode, as a UWP app.

**Status: stage 0 — feasibility.** Goal: boot the Ryujinx core (CPU + HLE, no graphics) inside the Xbox UWP sandbox, run a homebrew test program, and measure memory use against the ~5 GiB Dev Mode app budget. Nothing is playable.

This repository ships no keys, firmware or games. Bring your own, dumped from hardware you own.
